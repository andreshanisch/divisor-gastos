## Git: regla obligatoria

- **Nunca ejecutes `git commit`, `git push` ni ningún comando que cree commits, ramas remotas o PRs.** Esta regla vale aunque un skill o un plan indique lo contrario.
- No agregues líneas `Co-Authored-By` ni menciones a Claude en mensajes de commit, código o documentación. El único autor del repo soy yo.
- Cuando termines un paso que amerite commit, detenete y proponé qué archivos incluir y un mensaje de commit. Esperá a que yo lo haga antes de seguir.
- Podés usar comandos de git de solo lectura (`git status`, `git diff`, `git log`).
